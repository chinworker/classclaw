## 2026-09-29 Windows 复查

- 在 Windows x64 上使用 .NET SDK 10.0.401 完成 Release 构建和 `win-x64` 自包含发布，结果为 0 警告、0 错误；发布目录包含 227 个文件、约 110 MiB，并包含 DPAPI 运行时程序集。
- 该轮 Windows 复查的 Core **16 项**、媒体逻辑 **5 项**、终端与摄像头相关服务端回归 **59 项**及 Ruff 静态检查通过。Core 16 项也与 [当前测试入口](tests/ClassroomMate.Tests/Program.cs) 的声明数量一致。
- 正常用户上下文的只读硬件枚举可发现屏幕、扬声器、摄像头、DirectShow 麦克风和中文 TTS，Core Audio 读数及 DPAPI `CurrentUser` 纯内存往返成功；受限沙箱会隐藏麦克风并阻止 DPAPI，不能用沙箱结果代替桌面用户结果。
- 修复配对成功后因登录启动项注册表受限而误报失败的问题，并在持久化前完整校验配对响应；修复服务端撤销摄像头配置后本机仍上报陈旧采集状态，以及仅音频授权时无法报告已连接的问题。
- 本轮未兑换真实配对码、未播放声音、未打开摄像头、未修改登录启动项，也未启动托盘程序写入本机设备数据；真实 UI/DPI、播放和采集仍按下方现场清单验收。

Core 覆盖本机 Kestrel/WebSocket 鉴权、重复投递、回执与撤销，以及过期拒绝、账本不留广播原文、崩溃不补播、断线取消和音量恢复异常处理。多段广播不得用后续成功覆盖先前失败，超过有效期的重复播报须在执行前拒绝。

复查还修复了媒体进程关闭异常时的清理、失败进程回收和停止状态回报，以及音量设备异常时的资源释放；打包脚本显式使用 UTF-8 读取元数据，并移除了导致干净缓存下缺少 Windows 框架运行时的还原限制。Windows 原生路径已重新编译，但这些硬件行为仍须在 Windows 上实测。

## 发布校验与现场验收

当前发布使用 Python 3.13.15 嵌入式运行时及 13 个锁定 SHA-256 的 Windows wheels，含 aiortc 1.15.0、PyAV 17.1.0。`SHA256SUMS.json` 覆盖 EXE、运行时、媒体组件、许可和安装脚本；ZIP 校验值另存 `dist/ClassroomMate-win-x64.zip.sha256`。二进制和下载缓存不提交 Git。

尚未验证：真实 Windows 启动/自启、DPAPI 的托盘持久化与恢复、安装与卸载脚本执行、WinForms 显示与 DPI、多屏拔插、中文 TTS 发音、Core Audio 音量恢复、DirectShow 摄像头/麦克风兼容性、任务管理器终止后的硬件释放，以及低配电脑 CPU/内存/带宽。Windows 可执行文件已交叉编译，未在本开发机运行；不能将上述协议和合成媒体结果当成硬件验收结果。具体现场清单见 [README](README.md)。

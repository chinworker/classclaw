# 综合分析

学生分析支持最近任意自定义日期范围，整合作业、考勤、行为、考试、值日和当前座位。作业指标含完成率、未交、迟交、订正；考勤含出勤率、迟到、缺勤、请假；行为含正负向与严重事件；成绩按满分标准化比较最近两场；值日含次数与完成率。

班级分析聚合学生指标，返回学生数、作业完成与未交、出勤、迟到缺勤人数、正负向行为类型、学科均分、值日均衡、关注学生和数据质量。周期对比分别计算当前周期与对照周期，再返回同口径差值。

关注规则默认包括：周期内未交不少于 3 次、迟到不少于 3 次、存在严重事件、最近标准化成绩下降至少 10%、两个以上维度同时异常。返回规则、指标、证据与建议关注方向；结果不是永久标签。

跨模块分析逐学生并列作业、考勤、行为、成绩和值日指标，只输出“同时出现”“可能相关”“值得关注”。它不输出因果推断。

`evidence` 的每项包含原始记录 `id`、日期、类型和摘要。`data_coverage` 给出各数据源条数；缺少作业、考试或行为数据时 `warnings` 明确说明。考勤无记录按业务规则视为出勤，但同时警告这不能证明点名已完成。
